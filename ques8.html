Box-Sizing Comparison

Default Box (content-box)

width: 250px;
padding: 40px;
border is added outside total size.
Border Box (border-box)

width: 250px;
padding: 40px;
border is included inside total size.

In the default content-box model, padding and border increase the box’s total size. With box-sizing: border-box;, padding and border are included inside the defined width, keeping the element’s overall size consistent.
